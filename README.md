## 🏗️ Краткое описание проекта

### Название проекта
**Local Messenger** - Локальный мессенджер для образовательных учреждений

### Тип проекта
Учебный клиент-серверный проект с полным циклом разработки

### Технологический стек
- **Backend:** FastAPI, SQLite, JWT (PyJWT), bcrypt, WebSocket
- **Frontend:** PyQt5, Python
- **Сеть:** HTTP/REST API + WebSocket для real-time
- **База данных:** SQLite с автоматической инициализацией

### Основной функционал
1. ✅ Аутентификация и регистрация (JWT токены, первый пользователь = админ)
2. ✅ Обмен текстовыми сообщениями (REST API + WebSocket уведомления)
3. ✅ Отправка изображений (PNG, JPG, GIF, BMP через base64)
4. ✅ Real-time уведомления (WebSocket с ping/pong поддержкой)
5. ✅ Управление сообщениями (удаление своих сообщений)
6. ✅ История переписки (загрузка и отображение)
7. ✅ Список пользователей с онлайн-статусами (обновление каждые 10с)
8. ✅ Административные функции (просмотр всех сообщений/пользователей через API)
9. ✅ Интерфейс с вкладками (несколько одновременных чатов)
